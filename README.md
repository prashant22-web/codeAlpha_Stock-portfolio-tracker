# Stock Portfolio Tracker 📈

A simple **Stock Portfolio Tracker** built using Python as a CodeAlpha task.

## 📌 About the Project

This project allows users to manage a basic stock portfolio through a simple command-line interface.

Users can add stocks, enter the quantity and price, view their portfolio, and calculate the total portfolio value.

## 🛠️ Technologies Used

* Python
* Lists
* Dictionaries
* Functions
* Loops
* Conditional Statements
* User Input

## 🎯 Features

* Add stocks to the portfolio
* Enter stock quantity and price
* View portfolio details
* Calculate total investment value
* Simple command-line interface
* Easy-to-use menu system

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python stock_portfolio.py
```

5. Follow the instructions shown in the terminal.
